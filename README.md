# 千帆 · 多账号浏览器

基于 Electron 的本地多账号浏览器管理器。支持按网站分组、自定义网站名称、统一手动/自动添加账号、账号搜索、独立持久化会话、窗口聚焦/关闭、重启恢复和删除账号数据。

## 运行

建议使用 Node.js 22.12 或以上（Electron 安装工具的版本要求）。

```powershell
npm install
npm start
```

```powershell
npm test
npm run check
```

## Windows 打包

```powershell
npm run build:win
```

生成 Windows x64 版本：

- `dist/QianfanBrowser-Setup-1.0.0-x64.exe`：安装版，可选择安装目录，创建桌面和开始菜单快捷方式。
- `dist/QianfanBrowser-Portable-1.0.0-x64.exe`：便携版，双击即可使用，无需安装 Node.js。
- `dist/win-unpacked/`：解包后的应用，完整复制该目录后可直接运行 `QianfanBrowser.exe`。

账号、登录状态和邮箱配置继续保存在 `%APPDATA%/qianfan-browser`，源码版、安装版和便携版使用同一目录；便携版数据不放在 exe 旁边。卸载默认保留数据。构建仅包含运行源码和图标，不包含测试账号、日志、截图或邮箱配置。Windows 图标资源由 `scripts/create-icon.ps1` 生成，修改图标后可重新运行该脚本再打包。

## 使用

左侧「管理网站」可新增网站，设置自定义名称和默认页面地址。同一域名只创建一个网站，所有账号按所属网站归组；左侧可切换单个网站，搜索支持账号、备注、网站名称和域名。分组标题旁的编辑按钮可修改网站名称或同域名下的默认页面。已有账号的网站不允许换域名；只有空网站可移除，避免误删账号。

页面只有一个「添加账号」入口。右侧抽屉先选择网站，然后切换「手动输入」或「自动生成」；前者输入账号标识，后者使用 Cloud Mail 创建邮箱，可设置本次邮箱前缀和数量。两种方式都支持备注和创建后打开窗口，抽屉内可直接新增网站。

进入独立窗口后正常登录；同一网站的各账号 Cookie、Local Storage、IndexedDB、缓存彼此独立。关闭窗口不会清除登录状态。「打开窗口」恢复账号最近访问的页面，已打开时聚焦窗口。网站弹窗在同一账号会话内打开，关闭账号会关闭其全部窗口。分组右上角可批量打开该网站账号；分组菜单可批量关闭窗口，账号菜单可关闭或删除单个账号。

旧版账号数据启动时自动升级为网站分组结构，并在同目录保存 `accounts-v1-backup.json`。迁移按原网站域名归组，不改变账号 UUID、登录会话分区、邮箱绑定和最近页面；自动生成的默认网站名称可在管理网站中修改。

开启「重启后恢复账号窗口」后，退出管理器或通过 Ctrl+Q 退出，再启动会恢复之前打开的账号、最近页面、窗口大小、位置及最大化状态。关闭管理器会退出整个应用。关闭的账号不会在重启时自动打开。每个账号的附属弹窗不会逐个重建。网站自身要求重新验证、主动登出或使登录过期时仍需重新登录。

账号元数据保存在 Electron `userData` 目录的 `accounts.json` 中，登录状态由 `persist:account-<UUID>` 分区保存在同目录。Windows 通常为 `%APPDATA%/qianfan-browser`。数据不上传云端。删除账号需在原生确认框中确认，将关闭窗口并清除该分区的 Cookie、网站存储和缓存。

远程页面关闭 Node.js 集成、启用上下文隔离和沙箱，不加载管理器 preload，无法调用账号管理 IPC。网址仅允许 HTTP/HTTPS。相机、麦克风、定位等网站权限默认拒绝。暂未实现下载管理、代理、扩展和安装包构建。

## Cloud Mail 邮箱生成与验证码

点击左侧「邮箱服务设置」或自动生成模式中的「配置」，设置 API 地址、管理员邮箱、管理员密码、已在 Cloud Mail 配置的邮箱域名和默认地址前缀。点击「测试连接」可验证登录，再保存配置。预填 API、管理员邮箱和域名来自界面参考；密码需在应用内填写，没有写入源码。

在「添加账号」抽屉中选择网站和「自动生成」，填写本次邮箱前缀及数量（1–20）。应用通过 Cloud Mail `/api/login` 和 `/api/account/add` 创建管理员名下的邮箱地址，并将每个邮箱绑定到所选网站的独立浏览器账号。这些地址用于收信，邮箱归管理员管理，不是带独立密码的新 Cloud Mail 用户；第三方网站注册在账号窗口中完成。

账号行提供「复制账号」按钮：邮箱账号复制邮箱地址，普通账号复制账号标识。「验证码」查询该邮箱过去 15 分钟的邮件并识别 4–8 位字母数字验证码，优先匹配验证码附近的内容，不将版权年份当作验证码。默认展示最新邮件；有多封邮件时可切换，不会因为最新邮件无法识别而自动使用旧邮件的验证码。

验证码弹窗显示主题、发件人、接收时间和邮件原文；HTML 原文以文本形式查看，不执行脚本或加载远程内容。识别不明确时，在原文中选中验证码后点击「使用选中内容」，或在「手动填写或修改验证码」输入框中填写，然后点击「复制验证码」。多个不同验证码候选会交由手动选择。

「等待新验证码」从点击前 30 秒起查询，每 5 秒重试，最多 2 分钟；收到邮件后显示原文供核对，即使无法识别也可手动选取。仅返回收件地址、邮箱 ID、收信时间匹配的邮件。关闭验证码弹窗会停止后续轮询。

配置保存在 Electron userData 的 `cloud-mail.json`，管理员密码使用 Electron `safeStorage` 加密（Windows 使用系统 DPAPI），不会返回给管理界面。更换 API 或管理员邮箱需重新输入密码；旧账号查询需使用创建时的同一套服务配置。网站页面没有权限访问这些接口。删除本地浏览器账号不删除 Cloud Mail 上的邮箱。

服务启用了创建邮箱人机验证或域名未配置时，创建可能失败并显示错误，不自动绕过验证；批量创建失败时，已成功的账号保留。接口请求超时后不自动重复创建，避免重复邮箱。接口实现参考 [Cloud Mail 官方文档](https://doc.skymail.ink/api/api-doc)。测试采用模拟邮件服务，不向真实邮箱发送邮件。

## 手动验收

1. 为同一网站创建两个账号，分别登录不同身份；刷新和重新打开，确认互不串号。
2. 退出应用并重启，确认登录态、打开的账号和窗口位置恢复。
3. 关闭其中一个账号，退出再重启，确认只恢复仍打开的账号。
4. 关闭自动恢复后重启，确认管理器启动但账号窗口不自动打开；手动打开仍保留登录态。
5. 打开网站弹窗，确认沿用所属账号会话；关闭账号确认全部窗口关闭。
6. 删除账号，确认其他账号登录不受影响，新建账号无法继承已删除账号状态。
